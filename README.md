# Language inter-operation

Subdirectories indicate the language the examples it contains are to be run
from. They contain further subdirectories for the examples coupling to other
languages.

## Contents

* [C](./c)
  * [Calling C++ from C](./c/cpp)
  * [Calling Fortran from C](./c/fortran)
  * [Calling Python from C](./c/python)
* [C++](./cpp)
  * [Calling C from C++](./cpp/c)
* [Fortran](./fortran)
  * [Calling C from Fortran](./fortran/c)
* [Python](./python)
  * [Calling C from Python](./python/c)

## Setup

Create a Python virtual environment, activate it, and install the Python
dependencies with
```sh
pip install -r requirements.txt
```
